# 秋招作战台

一个轻量、隐私优先的秋招进度管理工具，帮助你记录岗位、追踪流程、准备面试，并复盘每一次经历。

## 功能

- 岗位看板：想投递、已投递、已测评、已笔试、已一面、已二面、已终面、Offer、已挂、拒绝
- 拖拽岗位卡片，直接更新申请阶段
- 投递意愿：随便投投、可以去、真想去、梦中情岗
- 记录企业类型：国央企、私企、外企
- 记录岗位链接、岗位描述、岗位要求和备注
- 粘贴整段 JD，自动识别企业、岗位、城市、岗位描述和岗位要求
- 面试记录：问题、结果反馈、下一步改进
- 秋招日程：统一展示面试、网申截止、笔试、测评截止、宣讲会、材料提交等事件
- 点击日历日期筛选当天事件，并可返回全部事件；过期事件自动排列在底部
- 点击事件可查看备注并修改，日程列表默认只显示事项和日期
- 准备中心：增加、编辑、回答和删除高频问题

## 快速开始

1. 下载或克隆本仓库。
2. 直接用浏览器打开 index.html。
3. 点击“新增岗位”，填写企业、岗位、企业类型和投递意愿。
4. 复制招聘网站的 JD 到“智能识别”区域，点击“识别并填充”，检查后保存。
5. 在“岗位追踪”中拖动卡片更新阶段。
6. 在“秋招日程”中记录面试或新增重要时间节点。
7. 点击日历中的日期查看当天全部事件，点击“返回全部”恢复完整列表。
8. 点击右侧事件可查看备注并修改内容。

## 隐私与数据安全

本项目是前端静态应用，不需要登录，也不依赖服务器。岗位、面试、待办、时间节点和笔记默认只保存在你当前浏览器的 localStorage 中，不会自动上传到 GitHub 或其他服务器。

GitHub 仓库只包含程序代码和使用说明，不包含任何个人投递记录。使用者之间的数据彼此隔离：每个人在自己的浏览器中打开应用，看到的是自己的本地数据。

请注意：

- 不要把导出的 JSON 备份、个人 JD、面试复盘、截图或本地数据库提交到公开仓库。
- 清理浏览器站点数据、更换浏览器或更换设备可能导致本地数据丢失。
- 如果自行恢复数据导出功能，请将备份文件保存在 GitHub 仓库之外的安全位置。
- 如果未来接入云同步，应额外设计登录、权限和加密机制。

## 本地开发

项目没有构建依赖，修改 HTML、CSS 或 JavaScript 后刷新浏览器即可。为了避免浏览器缓存，刷新时可以使用 Ctrl + F5。
